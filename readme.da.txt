Schedule Message er en Homey-app, der lader dig sende beskeder på et bestemt tidspunkt. Disse beskeder kan behandles af andre apps som Telegram, WhatsApp, Signal eller Slack. Automatiser påmindelser, notifikationer eller egne beskeder.

Funktioner:
- Planlæg beskeder til dato og tid
- Understøtter kategorier og modtagere
- Kompatibel med andre Homey-apps
- Avanceret integration via rå input

Brug:
1. Installer appen på Homey.
2. Opret et flow med "Planlæg besked"-kortet.
3. Indtast besked, dato, tid og evt. modtager/kategori.
4. Beskeden sendes på det planlagte tidspunkt.

Avanceret:
- Brug "Planlæg besked (rå)" med format:  
  `dato|tid|modtager|besked`  
  Eksempel: `04-12-2025|12:00|+4520123456|Hej verden`
- Du kan også bruge et præfiks til at fjerne data.
