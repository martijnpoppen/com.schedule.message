Schedule Message ist eine Homey-App, mit der Sie Nachrichten zu einem bestimmten Zeitpunkt senden können. Diese Nachrichten können von anderen Apps wie Telegram, WhatsApp, Signal oder Slack verarbeitet werden. Automatisieren Sie Erinnerungen, Benachrichtigungen oder eigene Nachrichten.

Funktionen:
- Nachrichten zu Datum und Uhrzeit planen
- Kategorien und Empfänger unterstützen
- Kompatibel mit anderen Homey-Apps
- Erweiterte Integration über Rohdaten

Verwendung:
1. App auf Homey installieren.
2. Flow mit "Nachricht planen" Aktionskarte erstellen.
3. Nachricht, Datum, Uhrzeit und ggf. Empfänger/Kategorie eingeben.
4. Die Nachricht wird zum gewählten Zeitpunkt gesendet.

Erweitert:
- Verwenden Sie "Nachricht planen (roh)" für Eingaben wie:  
  `Datum|Uhrzeit|Empfänger|Nachricht`  
  Beispiel: `04-12-2025|12:00|+491601234567|Hallo Welt`
- Optional kann ein Präfix entfernt werden.
