Schedule Message est une application Homey qui permet d’envoyer des messages à une heure précise. Ces messages peuvent être traités par d’autres applications comme Telegram, WhatsApp, Signal ou Slack. Automatisez rappels, notifications ou messages personnalisés.

Fonctionnalités :
- Planification de messages à une date et heure précises
- Catégories et destinataires optionnels
- Compatible avec d’autres apps Homey
- Intégration avancée via saisie brute

Utilisation :
1. Installez l’application sur Homey.
2. Créez un flow avec la carte "Planifier un message".
3. Saisissez le message, la date, l’heure et éventuellement le destinataire/catégorie.
4. Le message sera envoyé à l’heure prévue.

Avancé :
- Utilisez "Planifier un message (brut)" au format :  
  `date|heure|destinataire|message`  
  Exemple : `04-12-2025|12:00|+33612345678|Bonjour le monde`
- Un préfixe peut être supprimé si besoin.
