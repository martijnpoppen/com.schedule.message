Schedule Message — это приложение для Homey, позволяющее отправлять сообщения в заданное время. Сообщения могут обрабатываться другими приложениями, такими как Telegram, WhatsApp, Signal или Slack. Автоматизируйте напоминания, уведомления или свои сообщения.

Возможности:
- Планирование сообщений по дате и времени
- Поддержка категорий и получателей
- Совместимость с другими приложениями Homey
- Продвинутая интеграция через raw-ввод

Использование:
1. Установите приложение на Homey.
2. Создайте поток с действием "Запланировать сообщение".
3. Введите сообщение, дату, время и, при необходимости, получателя/категорию.
4. Сообщение будет отправлено в назначенное время.

Дополнительно:
- Используйте "Запланировать сообщение (raw)" в формате:  
  `дата|время|получатель|сообщение`  
  Пример: `04-12-2025|12:00|+79161234567|Привет, мир`
- Можно использовать префикс для удаления данных.
